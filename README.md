# 病痛藥好簡報教練（pbp-presentation）

一個裝進 Codex 的小助手：把任何主題整理成「問題導向」的簡報。

## 它做什麼？

你丟給它一份工作清單、一場分享會的題目、週報或一段還沒想清楚的想法，它會幫你整理成聽眾在意的四件事，叫做「病痛藥好」：

| 格 | 回答的問題 | 例子 |
|---|---|---|
| 病 | 聽眾遇到什麼問題？ | 開完會，沒人記得誰要做什麼 |
| 痛 | 不處理會怎樣？ | 事情掉在地上，下週又要再開一次會 |
| 藥 | 你的解法是什麼？ | 會議錄音交給 AI，整理成「決議／待辦／負責人」三欄 |
| 好 | 解決後變多好？ | 散會十分鐘內，每個人都收到自己的待辦 |

做成簡報時，每頁標題都是一個問句，內文回答它，下一頁再丟出下一個問題。聽眾會一路跟著你想。開場先說「聽完你能帶走什麼」，結尾回到開場那個問題，再請聽眾做一件小事。

## 怎麼安裝？（不需要 GitHub 帳號）

**方法一：請 Codex 幫你裝（推薦）**

1. 在 Codex 開一個資料夾當專案。
2. 把下面這句貼進 Codex 送出：

```text
請從 https://github.com/NTU-Sherlock/pbp-presentation-skill 下載這個技能，把裡面的 pbp-presentation 資料夾安裝到這個資料夾的 .agents/skills/ 裡，裝好後告訴我怎麼叫出來。
```

3. 裝好後，在輸入框打 `$`，看得到 `pbp-presentation` 就成功了。

**方法二：自己下載**

1. 用瀏覽器打開 https://github.com/NTU-Sherlock/pbp-presentation-skill
2. 按綠色的「Code」→「Download ZIP」（不用登入）。
3. 解壓縮，把 `pbp-presentation` 資料夾放進你專案的 `.agents/skills/` 裡。

## 怎麼感受差別？

裝之前、裝之後，各用同一句請 Codex 做一次，比較兩份大綱：

```text
下週我要在部門分享會講 15 分鐘，主題是「我怎麼用 AI 整理會議記錄」。我想講：用了哪些工具、錄音怎麼轉成文字、怎麼請 AI 摘要，還有幾個小技巧。請幫我做成三頁簡報大綱。
```

裝好後在句子前面加上 `請用 $pbp-presentation`。模型建議選 **GPT-6.1 Sol**（推理中等），寫稿類的任務它最守規則。

- **裝之前**：通常會照你列的順序排成「工具介紹 → 操作步驟 → 小技巧」，像一份說明書。
- **裝之後**：它會先找出聽眾的困擾（開完會沒人記得誰要做什麼），把工具和步驟收進「解法」，每頁標題變成聽眾心裡的問題，結尾請大家下次開會試一次。

想看完整的前後對照，讀 [`pbp-presentation/references/example-sharing-talk.md`](pbp-presentation/references/example-sharing-talk.md)。

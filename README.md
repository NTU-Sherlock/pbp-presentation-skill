# 病痛藥好簡報教練（pbp-presentation）

一個裝進 Codex 的小助手：把任何主題整理成「問題導向」的簡報。

## 它做什麼？

你丟給它一份工作清單、週報、提案或一段想法，它會幫你整理成聽眾在意的四件事，叫做「病痛藥好」：

| 格 | 回答的問題 | 例子 |
|---|---|---|
| 病 | 對方遇到什麼問題？ | 12 個據點只交回 5 份用電資料 |
| 痛 | 不處理會怎樣？ | 年度盤點可能趕不上查證時程 |
| 藥 | 你的解法是什麼？ | 逐一打電話找出卡關原因，改成一頁表單 |
| 好 | 解決後變多好？ | 兩週內收齊 12 份，盤點如期完成 |

做成簡報時，每頁標題都是一個問句，內文回答它，下一頁再丟出下一個問題。聽眾會一路跟著你想。

## 怎麼安裝？（不需要 GitHub 帳號）

**方法一：請 Codex 幫你裝（推薦）**

1. 在 Codex 開一個資料夾當專案。
2. 把下面這句貼進 Codex 送出：

```text
請從 https://github.com/NTU-Sherlock/pbp-presentation-skill 下載這個技能，把裡面的 pbp-presentation 資料夾安裝到這個資料夾的 .agents/skills/ 裡，裝好後告訴我怎麼叫出來。
```

3. 裝好後，在輸入框打 `$`，看得到 `pbp-presentation` 就成功了。

**方法二：自己下載**

1. 用瀏覽器打開 https://github.com/NTU-Sherlock/pbp-presentation-skill
2. 按綠色的「Code」→「Download ZIP」（不用登入）。
3. 解壓縮，把 `pbp-presentation` 資料夾放進你專案的 `.agents/skills/` 裡。

## 怎麼感受差別？

裝之前、裝之後，各用同一句請 Codex 做一次，比較兩份大綱：

```text
我這個月做了三件事：整理了部門的檔案、辦了一場內部分享會、更新了兩份對外文件。請幫我做成給主管看的三頁簡報大綱。
```

裝好後在句子前面加上 `請用 $pbp-presentation`。你會看到它先問「主管在意什麼問題」，把三件事收斂成一條主線，每頁標題變成問句，數字和限定詞也會照原樣保留。

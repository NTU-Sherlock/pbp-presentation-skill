# 三個練習情境：看見工作背後的問題

> 以下情境都是本 skill 作者自編的虛構範例，用來練習「病痛藥好」，不是任何課程的原題，也不是真實公司的績效。

每個情境都先問：這位聽眾最需要理解或決定什麼？再選主線。

## A｜週報：客服回覆太慢

**聽眾**：部門主管。

**工作清單**：整理常見問題、寫了十題標準回覆、參加兩場會議、更新排班表、幫忙搬辦公室。

**問題標題：怎麼讓客人的問題更快得到回覆？**

| 格 | 寫法 |
|---|---|
| 病 | 同樣的問題每天被問很多次，每次都從頭打字回覆 |
| 痛 | 客人等太久會不耐煩，同事也被重複問題卡住 |
| 藥 | 整理出最常見的十個問題，各寫一則標準回覆 |
| 好 | 這十類問題改用標準回覆後，回覆時間明顯縮短（請放你實際量到的前後數字） |

**補充**：排班表更新，交代完成即可。**捨掉**：開會次數、搬辦公室，這次主管不需要據此做決定。

## B｜提案：要不要導入共用行事曆

**聽眾**：團隊所有人。

**素材**：大家各用各的行事曆、常常約會議撞期、想試一個共用行事曆。

**問題標題：為什麼我們約一場會要來回問三次？**

| 格 | 寫法 |
|---|---|
| 病 | 每個人的行程分散在不同工具，約會議要逐一詢問 |
| 痛 | 光是喬時間就花掉不少訊息往返，還常撞期 |
| 藥 | 試用一個共用行事曆一個月，大家把會議時段放上去 |
| 好 | 預期：約會議時一眼看出共同空檔（還沒試，所以寫成預期目標，並說好一個月後怎麼檢查） |

## C｜成果報告：新人上手太慢

**聽眾**：部門主管與新進同事的帶人學長姐。

**工作清單**：寫新人手冊、錄三支操作影片、安排導師、辦了一次歡迎午餐。

**問題標題：怎麼讓新人第一週就能自己完成基本工作？**

| 格 | 寫法 |
|---|---|
| 病 | 新人第一週大多在等人有空教 |
| 痛 | 新人焦慮，學長姐也被同樣的問題反覆打斷 |
| 藥 | 把最常問的操作寫成手冊、錄成短影片，再配一位固定導師 |
| 好 | 這一梯新人第一週就能獨立完成三項基本工作（請放你實際觀察到的結果） |

**補充**：歡迎午餐是好的氛圍營造，但這次報告的判斷重點是上手速度，可以放在最後一句帶過。

## 換一位聽眾，再練一次

同一份工作清單，對主管談效率，對新人可能談「第一週會遇到什麼、可以找誰」。每次換聽眾，先重新問：他最需要理解或決定什麼？

# 三個 PBP 案例：看見工作背後的問題

以下依葉丙成台大簡報課 W4 的三個虛構教學情境與選題示範，以編者自己的文字縮寫。四格與解讀是學員整理，並保留原題資料的證據範圍；不是老師逐字答案，也不是真實公司的績效。

三案要學的是選題與價值連結。練習時可以換受眾，觀察主線如何改變；案例中被省去的工作，換一場報告仍可能重要。

## A｜行銷週報：從做表單到會員取得

**聽眾**：行銷經理。

工作清單包括：分析註冊數據、改手機表單、分類客服來信、寫 FAQ、做社群圖片、測發文時間，以及開會、搬紙箱、訓練、更新行事曆。

如果照工作順序報，表單改動只會像其中一件任務。課堂示範把它拉成主線，讓主管看到註冊問題與會員取得的關係。

**問題標題：如何減少手機註冊阻力，讓更多人完成註冊？**

| 格 | 示範重寫 |
|---|---|
| 病 | 手機訪客註冊時需填十一個欄位，流程有填寫阻力 |
| 痛 | 繁複流程可能阻礙訪客成為會員，影響行銷取得會員的目標 |
| 藥 | 分析過去三個月數據，把表單從十一欄精簡為五欄，週三上線 |
| 好 | 週四起每日完成註冊由平均三十八人增至六十一人，約增六成；續追流量與完成率 |

**其他**：客服一千二百封來信的分類、十二題 FAQ 草稿，以及社群測試；還沒有成效資料，交代產出與如何追蹤即可。FAQ 可建議看同類來信占比與回覆時間，社群看可比較條件下的觸及與互動；這些是編者提出的追蹤方法。

**省去**：例行週會紀錄、搬紙箱、資安訓練、行事曆更新。原因是目前未連到這場的註冊改善判斷。

**學到的思考**：把欄位減少連到使用者的阻力，再連到行銷目的；有成果的主線多講，尚未有成果的項目說明進度與追蹤。

**正式資料要注意**：三十八至六十一是完成註冊人數，約增加 60.5%，不是完成率、不是翻倍。原題未給手機流量占比、漏斗中途放棄數量或因果實驗，不補成肯定事實。

## B｜迎新報告：從籌備量到新生參與

**聽眾**：系主任與系學會會長。

工作包括籌備會議、T 恤比價、宣傳、逐一詢問未報名者、改日期、交通議價、急救訓練、場勘與整理社辦。課堂示範先看迎新的目的，選參與問題為主線。

**問題標題：如何提高迎新參與，讓更多新生有機會建立連結？**

| 格 | 示範重寫 |
|---|---|
| 病 | 上次報告只有四十一名新生報名，全系共八十二人，涵蓋半數 |
| 痛 | 部分新生少一次迎新交流機會，活動的連結目的受限 |
| 藥 | 私訊二十三名未報名者，發現十四人與期中考撞期，協調延後一週 |
| 好 | 報名增至六十七人，約占全系 81.7%；後續確認實際到場 |

**其他**：交通預估費用由五萬六千元降至三萬九千元；十二名隊輔完成急救訓練。前者是預估預算改善，後者是安全準備成果。

**省去**：開過幾次會、整理社辦，以及尚未連到報名成果的影片觀看數。三百八十次觀看沒有目標或比較基準，不直接評為低。

**學到的思考**：宣傳次數沒有回答新生為什麼不來；逐一詢問→找到撞期原因→調整日期，才能說清解法的針對性。

**正式資料要注意**：半數報名不能直接證明活動辦不成，報名也不等於到場或人際關係已改善。如果聽眾這次要拍板交通預算或安全安排，這兩項可以升為主線。

## C｜工程週報：從技術修改到產品體驗與口碑

**聽眾**：產品總監。

工作包括分析商店評論、追查舊機閃退、改圖片載入、改善首頁速度、寫測試，以及跨部門會議、面試、升級套件、修錯字與框架研究。

課堂示範讓總監看到產品口碑與新用戶意願，把閃退當成可處理的原因，首頁速度另列補充。

**問題標題：如何處理閃退負評，改善 App 的體驗與口碑？**

| 格 | 示範重寫 |
|---|---|
| 病 | 一星評論中有 41% 提到閃退，使用者遇到穩定性問題 |
| 痛 | 閃退中斷操作，負面口碑可能降低新用戶下載意願 |
| 藥 | 分析二千三百則評論，追到舊款手機記憶體不足，修改圖片載入方式 |
| 好 | 舊款手機閃退率由 3.2% 降至 0.4%；另觀察商店評分由 3.6 升至 4.1 |

**其他**：首頁載入時間由 4.8 秒降至 1.9 秒，作另一項體驗改善。

**省去**：本次未直接幫助判斷的會議、面試與錯字等細節。未有結論的框架研究可暫不放主體；若本場正要選框架，就應保留其比較與待決事項。

**學到的思考**：工程指標要接回使用者與產品目的；評論分析也要展示它如何找到可處理的原因。

**正式資料要注意**：41% 的分母是一星評論，不是全部二千三百則。保留「舊款手機」範圍；評分改善可並列，但不全歸因此次修正。原題沒給評分先跌、一星持續增加或實際下載損失，不能補寫。

## 換一位聽眾，再練一次

同一份迎新工作清單，對系主任談參與涵蓋率；對財務負責人可能先談預算；對安全負責人可能先談準備與待處理風險。這是編者提供的應用練習。

每次先問：這位聽眾最需要理解或決定什麼？再選主線。不要照抄案例的捨掉清單。
